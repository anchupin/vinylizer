# vinylizer

*[English version](README.md)*

Звук «с пластинки» для всего системного аудио macOS в реальном времени. Написан на Rust, без SoundSource.
Работает со встроенным DSP, а при желании хостит AU-плагин (например, iZotope Vinyl).
Настроен под маленькие Bluetooth-колонки вроде Marshall Emberton III.

Нужна macOS 14.2 или новее (Core Audio process taps).

## Сборка и запуск

```sh
./Vinylizer.command                           # собрать, установить в ~/Applications/Vinylizer.app и запустить
cargo build --release
./target/release/vinylizer                    # приложение в строке меню (по умолчанию)
./target/release/vinylizer --cli              # режим терминала: всё системное аудио → текущий выход
./target/release/vinylizer --cli --preset worn
./target/release/vinylizer --cli --app com.spotify.client   # только Spotify
./target/release/vinylizer --cli --au Vinyl         # iZotope Vinyl вместо встроенного DSP
./target/release/vinylizer --cli --au Vinyl --chain # iZotope Vinyl, потом встроенный DSP
./target/release/vinylizer --list-devices | --list-apps | --list-plugins
```

При первом запуске macOS попросит разрешение «System Audio Recording» (для приложения или, в режиме
CLI, для терминала). Без него tap отдаёт тишину. Выдать его можно в System Settings → Privacy & Security →
Screen & System Audio Recording.

В режиме CLI доступна консоль: `help`, `set crackle 0.5`, `preset shellac`, `bypass`, `meter`,
`au` (параметры AU), `au set <id> <v>`, `au presets`, `au preset <n>`, `quit`.

## Как это устроено

```
CATapDescription (global, exclude self | per-app), muteBehavior = mutedWhenTapped
        │  оригинальный звук приложений до колонки не доходит
        ▼
Private aggregate device: [колонка (clock master)] + [tap, drift compensation]
        │
        ▼  один HAL IOProc, realtime-поток Core Audio
tap buffer ──► DSP / AU ──► output buffer колонки
```

- **Без промежуточного буфера и лишнего потока.** Tap и устройство вывода живут в одном агрегате с общим
  клоком, поэтому вход и выход приходят в один callback. Встроенный DSP читает прямо из буфера tap'а и
  пишет прямо в буфер устройства. На AU-пути есть один deinterleave и один interleave: AU v2 работает с
  planar-форматом.
- **Горячий путь realtime-safe.** Нет аллокаций, локов, syscall'ов и логов. Параметры передаются через
  атомики с версионированием, коэффициенты фильтров пересчитываются раз в блок и только при изменении.
  `panic = "abort"`, поэтому unwind через FFI невозможен.
- **Без зависимостей**, кроме `libc`. Биндинги к CoreAudio, AudioToolbox, CoreFoundation и objc runtime
  написаны вручную (`src/ffi.rs`), раскладки структур проверены тестом.
- Если у устройства вывода есть микрофон (BT-гарнитура), его входные потоки отключаются через
  `kAudioDevicePropertyIOProcStreamUsage`, чтобы Bluetooth не переключился в HFP.
- При смене устройства вывода или выбранных приложений маршрут пересобирается сам.

### Приложение в строке меню

Клик по иконке открывает панель. Она не закрывается от кликов внутри, только от клика снаружи.
Интерфейс на русском и английском (переключатель «RU | EN» в шапке; пока язык не выбран, берётся язык
системы). Настройки сохраняются сами и переживают перезапуск. Три режима:

- **V2** — готовый звук под Emberton III, четыре ручки вместо семнадцати:
  - «Состояние» (новая → заигранная) согласованно двигает всё, что меняется с износом: пыль, щелчки,
    хлопки, шум канавки, глухоту верхов, плавание и искажения;
  - «Эпоха» (1930–2000) — полоса и характер записи своего времени, моно до 1955–1960;
  - «Громкость эффектов» двигает весь треск и шум вместе;
  - «Окраска» — тёплый винтажный тон всего звука.

  Стили «Обычный», «Джаз» (поношенная пластинка, 1958, стерео уже) и «Рок» (почище, ярче, 1972, фон и
  шум +6 dB против плотного мастера). Царапин нет, 33⅓, бас моно. Свои настройки вкладки Vinylizer, пока
  играет V2, откладываются и не теряются.

  Середина «Состояния» откалибрована по записи пустых промежутков настоящей LP
  ([Freesound #140295](https://freesound.org/people/joedeshon/sounds/140295/), joedeshon, CC BY 4.0)
  с помощью `examples/reference_stats.rs`, относительно её уровня шума: треск ~16 тиков/с почти вплотную
  к шуму (15,6 / 1,4 / 0,22 / 0,01 в секунду громче шума на +12 / +18 / +24 / +30 dB), щелчок — «звон»
  ~2 кГц длиной ~1,4 мс, шум розовый со спадом выше 4 кГц. Сверху — редкие громкие хлопки от крупных
  частиц (раз в ~40 с), которых у той чистой пластинки не было, но у поношенных бывают.
- **Vinylizer** — встроенный DSP, все параметры вручную: пресеты, свои пресеты («Сохранить»,
  «Сохранить как…», «Удалить…», «Сбросить» к «Тёплой»), «Без эффекта» для сравнения с оригиналом.
  Свои пресеты лежат в `~/Library/Application Support/Vinylizer/Presets/<имя>.preset`.
- **Плагин** — сторонний AU (например, iZotope Vinyl) со своими параметрами и пресетами; `.aupreset` в
  `~/Library/Audio/Presets/<производитель>/<плагин>/`, «Сбросить» загружает пресет плагина `Default`.
  Названия параметров показываются как их отдаёт плагин.

Когда ничего не играет (пауза, приложение закрыто), игла «поднимается»: после 3 с тишины на входе
(ниже −70 dBFS) треск и шум затихают за ~0,4 с и возвращаются за 20 мс, как только звук снова пошёл.
Паузы между треками короче 3 с треск сохраняют. В режиме плагина так же гасится его выход. Галочка
«Треск без музыки» это отключает: треск и шум идут всегда. Пока выбранное приложение на паузе или
закрыто, macOS не запускает его tap, поэтому «игла» играет отдельным IOProc прямо на устройство вывода
(микрофон не открывается) и уступает основному пути, как только тот снова работает. Только для
встроенного эффекта: сторонний плагин нельзя запустить в двух местах сразу.

### Встроенный vinyl DSP (`src/dsp.rs`)

| Параметр (`--set`) | В панели | Что делает |
|---|---|---|
| `wet` | Сила эффекта | сколько «пластинки» подмешано к оригиналу |
| `year` | Эпоха | 1930–2000: полоса записи (1930-е ~150 Гц–4,5 кГц, 1950-е ~60 Гц–10 кГц, с 1970-х полная), выпирающая середина у старых, моно до 1955, стерео с 1960 |
| `age` | Износ пластинки | завал верхов (18 → 5 кГц) и немного тепла на 200 Гц |
| `crackle` | Треск | сколько пылинок в секунду (до ~25) и шорох; почти все — тихий фон |
| `crackle_level` | Громкость фона | уровень обычных тихих тиков, от −55 до −25 dBFS |
| `clicks` | Щелчки | насколько тяжёлый «хвост»: громкость пылинок по степенному закону (чем громче, тем реже); показывается как «1 из N» пылинок на 15+ dB громче фона |
| `pops` | Хлопки | редкие громкие хлопки от крупных частиц, отдельно от пыли (до одного в 2 с) |
| `scratches` | Царапины | как часто появляется царапина (до 4 сразу): щёлкает раз в оборот 6–30 оборотов, потом пауза от 5 с до ~2 мин |
| `click_level` | Пик щелчков | потолок для щелчков, хлопков и царапин, от −40 до 0 dBFS; фон от него не зависит |
| `noise` | Шум поверхности | розовый шорох канавки со спадом выше 4 кГц, от −72 до −42 dBFS RMS, «дышит» с оборотом |
| `surface_gain` | Громкость эффектов | двигает фон, щелчки, хлопки, царапины и шум на одни и те же dB (−24…+24), но не дальше запаса пика щелчков до 0 dBFS («макс +N», если упёрлись) |
| `wow` | Плавание тона | детонация на частоте оборота + её 2-я гармоника, flutter 6,5 Гц |
| `drive` | Искажения иглы | в основном 2-я гармоника, сильнее на шипящих (RIAA-предыскажение) |
| `color` | Окраска | тёплый тон всей цепочки, и музыки, и треска: до +3,5 dB ниже ~300 Гц, −2 dB на 3,5 кГц, −4,5 dB выше ~6 кГц |
| `width` | Ширина стерео | 0 — моно; ниже 150 Гц всегда моно, как при нарезке |
| `gain` | Громкость | 0..2, линейно |
| `rpm` | Скорость | 0 = 33⅓, 1 = 45, 2 = 78 об/мин: период царапин и детонации |

Цепочка: модулированная задержка → HP 28 Гц → low-shelf → предыскажение → игла (чётная гармоника + очень
мягкий `tanh`) → обратная коррекция → DC-блок → 2×LP (износ) → полоса и середина эпохи → M/S (бас моно,
стерео эпохи) → треск и шум → окраска. Dry-сигнал берётся из той же линии задержки, так что при `wet < 1`
гребенчатого фильтра нет. Задержка 3 мс. На выходе мягкий лимитер с порогом 0,9, чтобы щелчки поверх
громкого мастера не клиповали.

Настроено под маленькую Bluetooth-колонку (Marshall Emberton III): эффект не генерирует того, что она не
сыграет, — ни рокота мотора, ни инфразвука коробления (они только съедают запас и дёргают лимитер колонки);
шум срезан ниже ~120 Гц, щелчки — ниже 150 Гц.

Пресеты: `new`, `subtle`, `warm` (по умолчанию), `worn`, `single` (45), `shellac` (78, моно), `jazz`,
`sinatra`, `jazz78`. Они построены из той же откалиброванной модели, что и V2 (`examples/gen_presets.rs`:
состояние пластинки, эпоха, окраска), так что пыль и шум у всех откалиброваны по настоящей пластинке; свои
у каждого только царапины, ширина стерео, громкость и скорость.

### Замеры

- `cargo run --release --example reference_stats -- file <wav>` и `-- model k=v ...` сравнивают любую
  запись винила с моделью: спектр шума по октавам, щелчки в секунду на каждом уровне над шумом, длину и
  яркость щелчка (всё относительно уровня шума самой записи).
- `cargo run --release --example surface_stats -- k=v ...` считает события треска в секунду по абсолютному уровню.

## Ограничения

- В режиме CLI окно AU-плагина не открывается, параметры меняются из консоли (`au`, `au set`).
- iZotope Vinyl должен быть авторизован, иначе он может выдавать тишину.
- При смене sample rate нужен перезапуск.
- Если программа упала, private tap и агрегат уничтожаются вместе с процессом, и звук возвращается сам.
